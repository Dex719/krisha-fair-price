# 🏠 Krisha Fair Price — справедливая цена квартир в Алматы

ML-сервис, который по ссылке на объявление Krisha.kz говорит: **переплата, выгодно или справедливая цена** — и объясняет почему (SHAP).

Стек: Python 3.11 · httpx + BeautifulSoup4 · SQLite · pandas · CatBoost · SHAP · FastAPI · Tailwind · Docker · aiogram (TG-бот) · GitHub Actions.

## 📋 План

Весь план разработки — в папке [`PLAN/`](PLAN/README.md). Начни с [`PLAN/README.md`](PLAN/README.md).

План написан под вайбкодинг с моделями уровня **Claude Sonnet / Gemini Flash**: каждый этап — маленькая задача с готовым промптом (копируй-вставляй), критериями проверки и сообщением коммита.

## 🗺️ Маршрут (4 недели)

| Неделя | Что делаем | Результат |
|---|---|---|
| 1 | Парсер + краулер + SQLite | 5 000+ объявлений в базе |
| 2 | Очистка + EDA + CatBoost + SHAP | Модель бьёт baseline, метрики записаны |
| 3 | FastAPI + фронтенд + Docker + деплой | Живая ссылка, работает с телефона |
