# requirements.lock (+ requirements-train.lock, requirements-runtime.lock, requirements.txt)
purpose: pinned flat dependency sets, all generated by `make lock` ([[code/Makefile]]) for linux x86_64 / py3.11.

## Files
- `requirements.lock` (130 lines) — `uv pip compile pyproject.toml`. Used by rescrape / rescrape-rent / restore-drill / backfill workflows; pip-audit in CI.
- `requirements-train.lock` (241 lines) — `--extra train -c requirements.lock`. Used by CI (test, e2e) and retrain.
- `requirements-runtime.lock` (110 lines) — `requirements.lock` minus catboost plotting tail, generated by [[code/scripts/gen_runtime_lock.py]]; Dockerfile only, `--no-deps` mandatory.
- `requirements.txt` — legacy floating list (Railway/Railpack); not used by CI or Docker.

catboost 1.2.10, fastapi 0.139.0, starlette 1.3.1, uvicorn 0.50.0, pydantic 2.13.4, pandas 3.0.3, numpy 2.4.6, scipy 1.17.1, h3 4.5.0, httpx 0.28.1, lxml 6.1.1, cryptography 50.0.1, pillow 13.0.0 (not in runtime lock), matplotlib 3.11.0 (not in runtime lock).
